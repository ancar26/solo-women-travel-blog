Personal travel blog for Anca Rada — solo female traveller, sports enthusiast, remote worker.

**Brand palette**: terracotta #C4622D, sand #F2E8D9, cream #FAF6F0, olive #6B7C4D, brown-dark #2C1810
**Fonts**: Playfair Display (headings), Lato (body)
**Book title**: "Count to 5 and Go"

**Why:** Static HTML site with warm earthy design, CSS already written with object-fit:cover for all image slots.
**How to apply:** When making future design decisions, respect the warm terracotta-dominant palette and editorial feel. Don't suggest cool blues or clinical whites.
